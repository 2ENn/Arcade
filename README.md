# Taoob Arcade

ห้องเกมรวม A-Math, Sudoku, เกม 24, หมากรุก, หมากฮอส พร้อมบัญชีผู้เล่น (ชื่อผู้ใช้ + รหัสผ่าน) และตารางอันดับรายคน
ใช้ GitHub Pages โฮสต์หน้าเว็บ และ Supabase เก็บบัญชี/อันดับ (รหัสผ่านถูกแฮชโดย Supabase Auth ไม่ได้เก็บเป็นข้อความธรรมดา)

## ตั้งค่า (ทำครั้งเดียว)

### 1) สร้างตารางใน Supabase (ถ้าเคยรันแล้ว ให้รันไฟล์ใหม่อีกครั้ง เพื่อเพิ่มหมากรุก/หมากฮอส รันซ้ำได้ปลอดภัย)
Supabase Dashboard → **SQL Editor** → New query → วางทั้งไฟล์ `schema.sql` → **Run**

### 2) ปิดการยืนยันอีเมล
Supabase Dashboard → **Authentication → Sign In / Providers → Email** → ปิด **Confirm email** → Save
(ระบบนี้ใช้ชื่อผู้ใช้ ไม่มีอีเมลจริง จึงยืนยันอีเมลไม่ได้)

### 3) อัปโหลดขึ้น GitHub
สร้าง repo (เช่นชื่อ `arcade`) แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ไว้ที่ราก:
```
index.html  platform.js  schema.sql  icons/  amath/  sudoku/  game24/  chess/  checkers/  .nojekyll
```
Settings → Pages → Deploy from a branch → `main` / `(root)` แล้วเปิด `https://<ชื่อ GitHub>.github.io/arcade/`

## หมายเหตุ
- ชื่อผู้ใช้ใช้ได้ a-z 0-9 และ _ ยาว 3–16 ตัว (ไม่สนตัวพิมพ์ใหญ่เล็ก) รหัสผ่านต้องมี 6 ตัวขึ้นไป (เบราว์เซอร์แปลงเป็นรหัสยาวด้วย SHA-256 ก่อนส่ง)
- **ลืมรหัสผ่าน:** กด "ลืมรหัสผ่าน? รีเซตรหัสผ่าน" ในหน้าเข้าสู่ระบบ ใส่ชื่อผู้ใช้ให้ตรง แล้วตั้งรหัสผ่านใหม่ + ยืนยัน (ไม่ใช้อีเมลหรือรหัสเดิม) ข้อควรรู้: ใครรู้ชื่อผู้ใช้ก็รีเซตรหัสของชื่อนั้นได้ จึงเหมาะกับกลุ่มเพื่อนเล่นกันเอง
- **ต้องรัน `schema.sql` ใหม่อีกรอบ** ใน Supabase SQL Editor เพื่อเพิ่มฟังก์ชันรีเซตรหัสผ่าน (รันซ้ำได้ ข้อมูลเดิมไม่หาย)
- ยังไม่ล็อกอินก็เล่นได้ แต่ผลจะไม่ถูกบันทึก
- ผลถูกส่งจากฝั่งเบราว์เซอร์ ผู้เล่นที่มีความรู้เทคนิคอาจแก้ตัวเลขได้ (ฟังก์ชันจำกัดแต้มต่อครั้งไม่เกิน 20) เหมาะกับการเล่นระหว่างเพื่อน
- แต้มรวม: ชนะระดับง่าย/กลาง/ยาก/โหด ได้ 1/2/4/8 (A-Math สู้ AI 2/4/8) ชนะเพื่อน 5 แต้ม ถ้าใช้ใบ้ไม่ได้แต้มและไม่นับเวลา
- ค่าเชื่อมต่อ Supabase อยู่บนสุดของ `platform.js` (ใช้ publishable key เท่านั้น ห้ามใส่ service_role key)
